# W4 report: router fixes from the answer eval

## 1. What I did and decided
- `router.py`, case 1 (unclear-no-doc): when several docs have the mentioned version, a doc is accepted only if the
  question names it (`named_in`). Otherwise the route is unclear with a list of the docs that have the version plus
  the which-doc list. No search guess any more.
- Cases 2 and 3: in `_resolve`, an LLM "unclear" with no doc, no version, no date becomes `latest` when the question
  is a general question (`_is_general_question`: at least 4 words, and no follow-up or change word such as other,
  that, it, same, changed, new, between, latest, previous). Search then picks the doc; the answer step refuses
  off-topic. I chose a code rule, not a prompt edit, because the prompt is not reliable for the 7B model and the
  "other one" / "forbidding agents" cases must stay unclear.
- `router_cases.json`: react/CLAUDE case replaced by "What changed in the latest data retention standard?"
  (compare, data-retention, v2 + v3).
