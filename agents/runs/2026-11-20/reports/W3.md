## 4. Failing cases, cause, file to change (this is task Q4)
1. **unclear-no-doc** "What changed in version 3?" Routed compare data-retention v2->v3 and answered. Expected unclear
   (refund, leave and retention all have v3). Cause: `router.resolve()` (router.py ~244-246): with several docs having
   the mentioned version it picks one by search (`top_doc(...)`) instead of asking. Fix: if more than one candidate
   doc and none is named in the question, return unclear + `_which_doc`. File: `src/vrag/router.py`.
2. **latest-semver-zeroes** "Can the numbers in a version have leading zeroes?" The router LLM said unclear (no doc
   named), so the user got "name the document". Cause: the question names no doc; for intent unclear the LLM
   was not nudged to latest. Fix: router prompt examples (a general question without a doc is latest), or in
   `resolve()` turn unclear-with-no-versions-and-no-doc into latest. File: `src/vrag/router.py`.
3. **latest-offtopic-password** "How do I reset my laptop password?" Same cause as 2 (routed unclear; the dress-code
   case, worded as a plain question, passes). Same fix. If the lead thinks unclear is acceptable for off-topic
   questions, relax the case instead (`intent: unclear`). File: `src/vrag/router.py` (or the case file).
4. **compare-retention-labels** "What changed between v2 and v3 of the data retention standard?" The answer
   mentions only change 1 (7 -> 5 years); the audit logs change (1 -> 2 years) is missing, though
   citations include it. Cause (likely): `answer.mentions_change` (answer.py:145) says change 2 is covered because the
   changed words ("1"/"2", "year"/"years") overlap with the words already said for change 1, so "Also changed:" is not
   added. Fix: compare against the section/clause identity too (section title "Logs" or the old/new number
   strings), not only stemmed key words. File: `src/vrag/answer.py`.
