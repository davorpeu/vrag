# vrag: rules

Read this file first, and again whenever you're unsure. `STATE.md` holds the current state, and this file
holds the rules.

## No human-time estimates (user, 2026-11-05)
Never consider how much human time a task would take. Don't estimate it, don't mention it, and don't use it to pick,
size, split, skip or defer work. Decide on what the task needs, not on hours or days.
